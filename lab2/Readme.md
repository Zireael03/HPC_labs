### MatMul
В ходе данной лабораторной работы был реализован алгоритм вычисления суммы элементов вектора на CPU и GPU с применением CUDA.

На CPU сумма вычисляется последовательным проходом по массиву. На GPU распараллеливание выполнено на уровне элементов: каждый поток обрабатывает свою порцию данных с помощью grid-stride loop. Это позволяет корректно обрабатывать векторы произвольного размера без жёсткой привязки количества элементов к количеству запускаемых блоков и нитей. Чтобы избежать состояния гонки при записи результата, используется атомарная операция atomicAdd. Каждый поток сначала накапливает частичную сумму в локальной переменной, после чего атомарно добавляет её в глобальную переменную на GPU. Такой подход сохраняет простоту реализации и гарантирует корректность результата при любом порядке выполнения потоков.

Также реализован точный замер времени: для CPU используется std::chrono, для GPU — cudaEvent_t, что позволяет измерить только время выполнения ядра без учёта асинхронных накладных расходов драйвера. Корректность результатов проверяется сравнением сумм CPU и GPU с учётом допустимой погрешности float, возникающей из-за разного порядка ассоциативных операций сложения.
