### MatMul
В рамках лабораторной работы была реализована задача перемножения матриц размером от 100×100 до 2000×2000 двумя способами: на CPU и на GPU с использованием CUDA. Распараллеливание выполнено на уровне элементов результирующей матрицы: каждый поток вычисляет одно значение C[i][j], что позволяет независимо обрабатывать миллионы элементов и максимально загрузить вычислительные ядра видеокарты. Эксперименты показали ускорение от 7,5× для малых матриц (100×100) до 264× для размеров около 1700×1700; снижение ускорения на максимальном размере (2000×2000) объясняется переходом в memory-bound режим, когда производительность ограничивается пропускной способностью памяти, а не вычислительной мощностью.
